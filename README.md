# Audit Evidence Readiness Checker

**Live application / Aplicación:** https://cyber-g3.github.io/audit-evidence-readiness-checker/

Available in **English and Spanish** from the language switch in the header.

A professional, privacy-first audit evidence screening tool for **NIS2**, **ISO/IEC 27001:2022**, **SOC 2** and **EU AI Act governance**.

## Why this is different

The tool does not confuse a documented control with audit readiness. It evaluates five independent assurance dimensions:

- implementation maturity — 30%
- evidence quality and traceability — 30%
- evidence freshness — 15%
- accountable ownership — 10%
- operating-effectiveness testing — 15%

## Capabilities

- Ten professional assurance domains with framework-aware references.
- Control-level owner, evidence reference, reviewer note and testing status.
- Executive score, evidence coverage, ownership and test-coverage KPIs.
- Priority heatmap and explained findings.
- 7/30/90-day remediation path.
- Fictional DemoCo scenario.
- Local browser persistence; no backend or account.
- JSON, Markdown and print/PDF export.
- Responsive SpectraSec design, technical SEO and GitHub Pages deployment.

## Professional boundary

This free screening provides decision support. It is not certification, a legal opinion or an independent audit conclusion. Scope, sampling, applicability and auditor-specific criteria must be validated by a qualified professional.
