# DemoCo — Assurance Review Scenario

> Fictional portfolio scenario.

## Situation
DemoCo has a documented access-control procedure and screenshots showing selected configurations. Management considers the control complete.

## Assurance review
The workbench evaluates the control across independent dimensions:

- implementation maturity;
- evidence quality and traceability;
- evidence freshness;
- accountable ownership;
- operating-effectiveness testing.

## Example result
Documentation exists, but:
- evidence is older than the review period;
- no current control owner is recorded;
- no operating-effectiveness test has been completed.

The control therefore should not be treated as audit-ready merely because a policy exists.

## Remediation
1. Assign accountable owner.
2. Refresh evidence from the authoritative source.
3. Define and execute an operating-effectiveness test.
4. Record exceptions/findings.
5. Remediate.
6. Retest.
7. Record the assurance conclusion.

## Portfolio lesson
The project models the distinction between documentation, implementation, evidence and operating effectiveness.
