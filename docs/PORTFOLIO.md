# Portfolio Case — Audit Evidence Readiness Checker

## Problem
A documented control is not necessarily implemented, evidenced, current, owned or operating effectively.

## Assurance model
The checker evaluates five independent dimensions:

| Dimension | Weight |
|---|---:|
| Implementation maturity | 30% |
| Evidence quality and traceability | 30% |
| Evidence freshness | 15% |
| Accountable ownership | 10% |
| Operating-effectiveness testing | 15% |

```text
Requirement
   ↓
Control
   ↓
Expected evidence
   ↓
Evidence review
   ↓
Control test
   ↓
Finding / remediation
   ↓
Retest
   ↓
Assurance conclusion
```

## What this demonstrates
- Assurance-oriented GRC modelling
- Framework-aware evidence screening
- Decision support separated from audit conclusions
- Executive KPIs and remediation prioritization
- Local-first privacy design
- EN/ES delivery

## Product direction
Evolve the checker into a broader assurance workbench interoperable with Security Evidence Collector and Security Control Mapper.

## Professional boundary
This is a screening and decision-support tool, not certification or an independent audit opinion.
